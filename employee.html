ตารางบันทึกเวลา

วันทำงานบริษัท: จันทร์–เสาร์ • วันอาทิตย์เป็นวันหยุด • คลิกช่องเพื่อเปลี่ยนสถานะ: ✓ ปกติ, S สาย, P ลากิจ, Sick ลาป่วย, A ขาด, H หยุด

✓ = มาปกติ S = มาสาย P = ลากิจ Sick = ลาป่วย A = ขาดงาน H = วันอาทิตย์/วันหยุดเสาร์ = วันทำงานปกติ
# ชื่อ - นามสกุล ตำแหน่ง

รายงานสรุปสถิติ

สรุปวันทำงาน (จันทร์–เสาร์), วันมาปกติ, มาสาย, ลากิจ, ลาป่วย และขาดงานของพนักงานตามช่วงเวลาที่เลือก

ℹ️ วันทำงานสุทธิ = วันที่บริษัทเปิดทำการจริง (จันทร์–เสาร์ ไม่รวมวันอาทิตย์และวันหยุดพิเศษ) • ปฏิบัติงานจริง = วันปฏิบัติงานจริง (✓ + S) − วันหยุด − วันลา (P + Sick) − วันขาด (A)
# ชื่อ - นามสกุล ตำแหน่ง มาปกติ (วัน) มาสาย (ครั้ง) ลากิจ (วัน) ลาป่วย (วัน) ขาดงาน (วัน) ปฏิบัติงานจริง

🕘 ประวัติการลงเวลาย้อนหลัง

เก็บประวัติระยะยาวใน Firestore • ค้นย้อนหลังตามปี / เดือน / พนักงาน / สถานะได้

ℹ️ ประวัติถูกเก็บระยะยาวใน Firestore และไม่ถูกลบเมื่อเอาพนักงานออกจากรายชื่อ • ค้นได้ตาม ปี / เดือน / พนักงาน / สถานะ • วันจันทร์–เสาร์เป็นวันทำงานปกติ • วันอาทิตย์เป็นวันหยุด • ปฏิบัติงานจริง = วันปฏิบัติงานจริง (✓ + S) − วันหยุด − วันลา − วันขาด
📊 สรุปแยกรายบุคคลตามตัวกรอง
แสดงจำนวน มาปกติ / มาสาย / ลากิจ / ลาป่วย / ขาดงาน / วันหยุด และวันทำงานจริงของแต่ละคน
รหัส ชื่อ - นามสกุล ปกติ สาย ลากิจ ลาป่วย ขาด หยุด ทำงานจริง
ยังไม่มีข้อมูลที่บันทึกตามตัวกรองนี้
